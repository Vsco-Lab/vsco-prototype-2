# LG에너지솔루션 vs CATL 비교 데이터

## 1. 핵심 경영 지표 비교 (2025년 기준)

### 1.1 재무 실적 비교

| 지표 | LG에너지솔루션 | CATL | 배율(CATL/LG) |
|------|--------------|------|-------------|
| 매출 | 23.7조원 | 423.7B CNY (≈80조원) | 약 3.4배 |
| 영업이익 | 1.35조원 | - | - |
| 순이익 | - | 72.2B CNY (≈13.6조원) | - |
| 영업이익률 | 5.7% | - | - |
| 매출 성장률 | -7.6% | +17.04% | - |
| 이익 성장률 | +133.9%(영업이익) | +42.28%(순이익) | - |

LG에너지솔루션은 매출 감소에도 수익성 개선에 성공했으나, CATL은 매출과 이익이 동시에 대폭 성장하며 압도적 규모 차이를 보인다.

### 1.2 생산 능력 및 출하량 비교

| 지표 | LG에너지솔루션 | CATL |
|------|--------------|------|
| 배터리 출하량(2025) | 비공개 (추정 120~150GWh) | 661 GWh |
| 생산 능력 | 추정 200GWh급 | 772 GWh |
| 건설 중 캐파 | 비공개 | 321 GWh |
| EV 배터리 출하량 | 추정 100GWh급 | 541 GWh |
| ESS 배터리 출하량 | 비공개 | 121 GWh |

CATL의 생산 능력과 출하량은 LG에너지솔루션의 약 4~5배 수준이다.

| 지표 | LG에너지솔루션 | CATL |

매출 대비 R&D 비율은 유사하나, 절대 투자 규모에서 CATL이 약 3.6배 앞선다.

### 3.2 지역별 매출 비교

| 지역 | LG에너지솔루션 | CATL |
|------|--------------|------|
| 본국(한국/중국) | 오창 생산 중심 | 69.4% |

LG에너지솔루션은 북미가 핵심 해외 시장이고, CATL은 유럽과 아시아 중심으로 해외 확장을 추진 중이다.

## 5. 글로벌 생산 거점 비교

### 5.1 생산 기지 수

| 지역 | LG에너지솔루션 | CATL |
|------|--------------|------|
| 본국 | 오창 등 2~3곳 | 10곳 이상 |
| 북미 | 미시간, 애리조나, 오하이오(매각), 캐나다 | 없음 (기술 라이선싱만) |
| 유럽 | 폴란드 1곳 | 독일, 헝가리, 스페인 3곳 |
| 아시아(본국 제외) | 중국(난징), 인도네시아 | 인도네시아 |

### 5.2 지역별 전략 차이

**북미**:
- LG에너지솔루션: 직접 투자·생산 중심, IRA 혜택 수혜
- CATL: 직접 진출 불가 (블랙리스트), 기술 라이선싱으로 간접 진출

**유럽**:
- LG에너지솔루션: 폴란드 단일 거점, 유휴 라인 전환 검토
- CATL: 3국 삼각 전략 (독일-헝가리-스페인), 100GWh+ 목표

**동남아**:
- LG에너지솔루션: 인도네시아 소규모
- CATL: 인도네시아 50억 달러 대규모 수직통합 투자
